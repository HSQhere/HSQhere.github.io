### 1. 三大核心学习范式（How to learn）

- **监督学习（Supervised Learning）**：训练数据**包含输入 $X$ 和真实标签 $Y$**，目标是学习 $X \to Y$ 的映射。
    
- **无监督学习（Unsupervised Learning）**：训练数据**只有输入 $X$，无标签**，目标是发现数据的潜在结构、规律或聚类模式。
    
- **强化学习（Reinforcement Learning）**：智能体（Agent）在环境（Environment）中通过“试错”与环境交互，基于**奖励（Reward）/惩罚**信号来学习最优决策策略。

## 二、 从感知机（Perceptron）到现代神经元

你的笔记第二页清晰地呈现了神经网络的进化起点：

### 1. 单层感知机 vs 现代神经元

|**特性 PDF**|**单层感知机 (Perceptron) PDF**|**现代神经元 (Neuron) PDF**|
|---|---|---|
|**层数**|单层|多层（深层深度学习）|
|**激活函数**|阶跃函数（非 0 即 1，不连续）|**Sigmoid / ReLU**（平滑、连续、可微）|
|**解决问题**|只能解决**线性可分**问题（画直线）|能拟合极复杂的**非线性**空间（画曲线）|
|**学习目标**|只要全部分对即可|追求**误差/损失函数最小化**|

### 2. 数学表达与逻辑门（与门/或门/与非门/异或门）

- **阈值表达**：$y = \begin{cases} 0 & (w_1 x_1 + w_2 x_2 \le \Theta) \\ 1 & (w_1 x_1 + w_2 x_2 > \Theta) \end{cases}$
    
- **引入偏置（Bias, $b$）**：将阈值 $\Theta$ 移到等式左边，记为 $b = -\Theta$：
    
    $$y = \begin{cases} 0 & (w_1 x_1 + w_2 x_2 + b \le 0) \\ 1 & (w_1 x_1 + w_2 x_2 + b > 0) \end{cases}$$
    

> 💡 **AI 历史上的关键转折点（异或问题 XOR）**：
> 
> - **单层感知机局限**：只能用一条直线分割空间，因此可以轻松实现 AND（与）、OR（或）、NAND（与非）逻辑门，但**绝对无法用一条直线分隔 XOR（异或）**。
>     
> - **多层感知机（MLP）的突破**：通过组合 NAND 和 OR，再接一个 AND（即**多层感知机/三层感知机**），成功用多条直线交叠解决了 XOR 异或问题！
>     

## 三、 神经网络的核心：激活函数（Activation Functions）

笔记中详细梳理了三种最基础也最重要的激活函数及其优缺点：

### 1. 阶跃函数（Step Function）

- **公式**：$h(x) = \begin{cases} 0 & (x \le 0) \\ 1 & (x > 0) \end{cases}$
    
- **致命缺点**：导数处处为 0（在 0 点不可导），**无法进行反向传播梯度计算**。
    

### 2. Sigmoid 函数

- **公式**：$h(x) = \frac{1}{1 + e^{-x}}$
    
- **笔记中总结的 4 大特性**：
    
    1. **可微性与梯度计算**：光滑、处处可微，能够平滑传播梯度，满足反向传播链式法则。
        
    2. **避免震荡**：平滑的梯度变化使权重更新平稳，防止训练剧烈波动。
        
    3. **输出连续性与概率归一化**：输出有界（$0 \sim 1$），天生适合作为**二分类任务**的概率预测。
        
    4. **致命缺陷（梯度消失）**：当 $\vert{}x\vert{}$ 很大时，导数趋近于 0（饱和区）。在深层网络中反向传播时，多个小于 1 的导数连乘会导致前层**梯度消失（Vanishing Gradient）**，因此现代深层网络中很少用在中间隐藏层。
        

### 3. ReLU 函数（修正线性单元）

- **公式**：$h(x) = \begin{cases} x & (x \ge 0) \\ 0 & (x < 0) \end{cases}$
    
- **优点**：计算极快；在 $x > 0$ 时导数恒为 1，**完美解决了正半轴的梯度消失问题**，是现代深度学习隐藏层的标准配置。
    

## 四、 输出层激活函数与代码实现

你的笔记第三页展示了网络层的组合策略与代码：

### 1. 任务类型与输出层激活函数的选择

- **中间隐藏层**：统一使用 **ReLU** 或 Sigmoid 激活。
    
- **输出层选择**：
    
    - **回归问题**：使用**恒等函数（Identity Function）**，直接输出连续实数。
        
    - **二分类问题**：使用 **Sigmoid 函数**，输出单一类别概率 $p \in (0, 1)$。
        
    - **多分类问题**：使用 **Softmax 函数**，输出概率和为 1 的概率分布向量。
        

### 2. Softmax 函数的防溢出改进（防 Overflow）

- **标准公式**：$y_k = \frac{\exp(a_k)}{\sum_{i=1}^n \exp(a_i)}$
    
- **数值溢出问题**：当输入 $a_k$ 很大时（如 $e^{1000}$），计算 $\exp$ 会导致计算机内存溢出（返回 `inf` 或 `nan`）。
    
- **代码改进原理**：分子分母同乘常数 $C' = \exp(-C)$（其中 $C = \max(a)$）：
    
    $$y_k = \frac{\exp(a_k - C)}{\sum_{i=1}^n \exp(a_i - C)}$$
    
- **Python 实现代码（对应笔记）**：
    
    Python
    
    ```
    import numpy as np
    
    
    def softmax(a):
      c = np.max(a)  # 找到输入中的最大值
      exp_a = np.exp(a - c)  # 减去最大值后求 exp，防止溢出[cite: 1]
      sum_exp_a = np.sum(exp_a)
      y = exp_a / sum_exp_a
      return y
    ```

## 五、 深度学习训练全流程（The Loop & Pipeline） 

|**阶段**|**核心步骤**|**关键操作与数学含义**|
|---|---|---|
|**一、数据准备**|**1. 数据预处理**|数据清洗、归一化 / 标准化|
||**2. 数据集拆分**|划分为 Train 训练集与 Val 验证集|
|**二、训练循环 (The Loop)**|**1. Forward Pass**|输入 $X \to$ 矩阵乘法 + 激活函数 $\to$ 得到预测值 $y_{\text{pred}}$|
||**2. Compute Loss**|计算预测值与真实值的误差 $L(y_{\text{true}}, y_{\text{pred}})$|
||**3. Backward Pass**|链式法则求导，计算参数梯度 $\frac{\partial L}{\partial W}$|
||**4. Update Weights**|优化器更新参数：$W \leftarrow W - \eta \cdot \text{Grad}$|
||**5. Iteration**|切换至下一个 Batch / Epoch，重复训练|
|**三、模型评估**|**评估与验证**|在 Val 验证集上测试泛化性能，检查是否过拟合|
### 1. 常用损失函数（Loss Functions）
* **回归任务（均方误差 MSE）**：$\text{MSE} = \frac{1}{n}\sum (y_{\text{true}} - y_{\text{pred}})^2$
* **分类任务（交叉熵损失 Cross-Entropy Loss）**：$\text{L} = -\sum y_{\text{true}} \log(y_{\text{pred}})$
### 2. 常用优化器迭代进化（Optimizers）
* **SGD（随机梯度下降）**：$W \leftarrow W - \eta \frac{\partial L}{\partial W}$（易陷入局部最优或鞍点）。 
* **Momentum（动量法）**：引入惯性，加速沿梯度方向的更新，减少震荡。 
* **Adam（自适应矩估计）**：结合了 **Momentum（一阶动量）** 和 **RMSProp（二阶动量）**，自适应调整每个参数的学习率，是目前深度学习中最主流的默认优化器。
## 六：反向传播与计算图（Computational Graph）

反向传播（Backpropagation）的本质，就是利用**计算图**和**微积分的链式法则（Chain Rule）**，以极高的效率计算损失函数对模型中每一个权重参数 W 的梯度 $\frac{\partial L}{\partial W}$。

### 1. 计算图的核心原理：正向 vs 反向

计算图将复杂的数学公式拆解为节点（算子，如 +, ×）和边（数据向量）：

- **正向传播（Forward Pass）**：从左往右计算，算 also 预测值和最终 Loss。
    
    PDF
    
- **反向传播（Backward Pass）**：从右往左传递，利用链式法则计算局部偏导数，并与上游传过来的梯度**相乘**。
    

Plaintext

```
正向： 输入 x, y ──► [ 节点 (如乘法) ] ──► 输出 z = x * y
                                             │
反向： 局部梯度 ∂z/∂x = y ◄── [ 节点 ] ◄──────┴── 上游梯度 (如 ∂L/∂z)
       最终梯度 ∂L/∂x = (∂L/∂z) * y
```

### 2. 两个最基础算子的反向传播规则

理解这两个基础节点的导数传递规律，就能推导整个神经网络：

|**节点类型**|**正向计算**|**反向传播计算（设上游梯度为 ∂z∂L）**|**核心物理含义**|
|---|---|---|---|
|**加法节点 (+)**|$z = x + y$|$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \times 1$|**梯度原封不动照搬传递**（相当于把上游信号直接分流发给每一个输入端）|
|**乘法节点 ($\times$)**|$z = x \times y$|$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \times y$<br><br>  <br><br>$\frac{\partial L}{\partial y} = \frac{\partial L}{\partial z} \times x$|**梯度翻转相乘**（把上游梯度乘以“另一个输入端的值”）|

### 3. 矩阵乘法（Affine 层）的反向传播

在神经网络中，数据是以矩阵/张量形式流动的：$\mathbf{Y} = \mathbf{X} \cdot \mathbf{W} + \mathbf{B}$。

- **梯度推导公式**（注意矩阵乘法的维度匹配与转置）：
    
    $$\frac{\partial L}{\partial \mathbf{X}} = \frac{\partial L}{\partial \mathbf{Y}} \cdot \mathbf{W}^T$$
    
    $$\frac{\partial L}{\partial \mathbf{W}} = \mathbf{X}^T \cdot \frac{\partial L}{\partial \mathbf{Y}}$$
    
    $$\frac{\partial L}{\partial \mathbf{B}} = \sum_{\text{batch}} \frac{\partial L}{\partial \mathbf{Y}}$$

> 💡 **为什么反向传播比直接求导快？** 如果用传统数值微分（如给每一个 w 加 0.0001 算变动），如果有 100 万个参数，就需要跑 100 万次前向传播！而反向传播只需要**一次正向 + 一次反向**，就能瞬间一次性算出所有 100 万个参数的梯度。

## 模块五：卷积神经网络（CNN）空间特征提取

传统全连接网络（Affine/FFN）处理图像时有两个致命缺点：**参数量爆炸** 且 **破坏了图像的二维空间结构信息**。为了解决这个问题，CNN 引入了卷积核（Filter/Kernel）。

### 1. CNN 的三大核心组件

一个标准的 CNN 架构主要由以下三种层交替堆叠而成：

#### ① 卷积层（Convolutional Layer）：提取空间特征

- **工作方式**：用一个固定大小的卷积核（Kernel）在输入图像上做滑动窗口内积计算（局部感受野）。
    
- **三大核心超参数**：
    
    - **卷积核大小（Kernel Size）**：如 $3 \times 3$ 或 $5 \times 5$。
        
    - **步长（Stride）**：卷积核每次移动的像素跨度（如 Stride=1 或 2）。
        
    - **填充（Padding）**：在图像外围补一圈 0，用于防止图像边缘边缘信息丢失，并控制输出大小。
        
- **输出特征图（Feature Map）尺寸计算公式**（必须熟记）：
    
    假设输入尺寸为 $H \times W$，Padding 为 $P$，Stride 为 $S$，Kernel 尺寸为 $K$：
    
    $$H_{\text{out}} = \frac{H + 2P - K}{S} + 1$$
    
    $$W_{\text{out}} = \frac{W + 2P - K}{S} + 1$$
#### ② 激活层（ReLU Layer）：注入非线性

- 在卷积计算之后紧跟非线性激活（通常用 ReLU），保留空间特征的同时赋予网络拟合复杂曲面的能力。
#### ③ 池化层（Pooling Layer）：降维与抗平移不变性

- **干了什么**：在局部区域内做下采样，把特征图变小（例如将 2×2 区域变成 1×1）。
    
- **两大主流池化**：
    
    - **最大池化（Max Pooling）**：取区域内最大值，提取最显著的特征（最常用）。
        
    - **平均池化（Average Pooling）**：取区域内平均值，平滑特征。
        
- **特点**：池化层**没有需要学习的权重参数**，通道数（Channel）保持不变，且对微小的平移/变形具有很强的鲁棒性。
    

### 2. CNN 的特征提取分层演进逻辑

CNN 之所以能在计算机视觉（CV）领域大放异彩，是因为它的多层叠加天然符合**人类视觉系统的分级认知规律**：

Plaintext

```
[ 原始图像输入 ]
       │
       ▼
[ 浅层卷积层 ] ──► 提取低级局部细节特征（边缘、线条、颜色斑块、角点）
       │
       ▼
[ 中层卷积层 ] ──► 将低级特征组合（纹理、局部轮廓、形状、眼睛/轮胎等局部器官）
       │
       ▼
[ 深层卷积层 ] ──► 抽象出高级语义特征（完整的人脸、汽车、猫/狗整体特征）
       │
       ▼
[ 全连接/Softmax ] ──► 输出分类概率（例如：98% 概率是猫）
```

## 知识体系全景收官地图

将你之前整理的手写笔记 与本次补充的内容衔接起来，就构成了完整的基础深度学习栈：

PDF

1. **基础思想**：感知机 → 激活函数（Sigmoid/ReLU） → 多层感知机（解决非线性与异或问题）。
    
2. **训练框架**：数据预处理 → 前向传播 → Loss 计算 → 反向传播（计算图与链式法则） → 优化器更新（SGD/Momentum/Adam）。
    
3. **架构分化**：
    
    - **处理一维表格/向量数据** → 全连接网络（MLP/FFN）。
        
    - **处理二维/三维网格数据（图像/视频）** → 卷积神经网络（CNN，利用局部感受野与权重共享）。
        
    - **处理序列数据/文本** → RNN/Attention → **Transformer**。
