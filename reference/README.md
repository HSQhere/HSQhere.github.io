# 博客重构 · 参考样稿

这里存放的是重构思路上产出的**视觉参考样稿**，不是最终站点代码。用途是确定方向后再照着实现，避免边写边改方向。

## v1

`v1/index.html` 是当前推荐方向，直接双击用浏览器打开即可（资源都在 `v1/assets/` 里，无需服务器）。

### 它包含什么

**首屏**是一整屏风景英雄区，左右分栏：

- 左：问候、名字、一句自述、两个入口按钮、四个标签
- 右：猫猫形象卡（这是我的虚拟形象），卡内下方是一言语录气泡
- 背景：山湖照片，全屏固定
- 进场：头像浮起 → “晚安 欢迎回来”逐字弹出 → 白雾向两侧散开 → 文案逐条浮现

**下滑**进入便当格板块页（参考 lvyovo-wiki 的卡片结构，圆角 64px、白色半透明玻璃、错落大小）：

| 位置 | 卡片 | 点进去是 |
| --- | --- | --- |
| 第一行左 | 站点导航卡 | 各板块入口 |
| 第一行中 | 日志（40 篇） | 归档 |
| 第一行右 | 图库预览 | 摄影图库 |
| 第二行左 | 计划（只读） | 学习计划 |
| 第二行中 | 朋友 | 友链 |
| 第二行右 | 关于 | 个人页 |
| 第三行左 | 成长路径 | — |
| 第三行右 | 书桌小物件（闹钟 / 磁带 / 便签 / 拍立得） | 分别通向时间页、音乐、计划、图库 |

主页不铺文章列表，文章只在进入“日志”之后出现。

### 书桌区

最后一排不是规整卡片，而是一张“桌面”：一个真实走针的闹钟、一盒转动的磁带、一张斜贴的便签、一张拍立得，外加一个虚线标签和一枚小别针。它们大小不等、角度各异、基线错开 20–48px，像随手摆在桌上；有一个很淡的桌沿线把它们串起来。

- 闹钟：指针按真实时间每秒走，秒针是暖橘色细针，表面有内阴影和玻璃高光
- 磁带：两个卷盘反向缓慢旋转，标签写着正在听的歌
- 便签：用一枚图钉“钉住”，记录本周计划
- 拍立得：山湖照片配手写日期

窄屏时这些物件自动变成可换行的一排，不再绝对定位。

### 动效

- **指针视差**：背景照片、三层光斑、网格、光束、文案、猫猫卡以不同幅度反向移动，猫猫卡另带 3D 倾斜（最大 12 度）
- **滚动视差**：背景照片随滚动位移，速度约为前景的 0.3 倍
- **便当格入场**：卡片按 80ms 间隔依次升起，成长路径的横线同时从左画到右
- **逐字弹跳 + 云开**：开场序列，约 2.4 秒，右下角可跳过

所有动效都遵循 `prefers-reduced-motion`，开启减少动态后直接显示最终画面。

### 响应式

- ≥1000px：标准左右分栏，中央留白最大；猫猫按 `clamp(300px, 26vw, 460px)` 随屏幕放大，卡片上限 520px，避免在 2K/4K 上被拉成横条
- 620–1000px：仍为左右分栏，标题、猫猫、间距按比例收缩
- <620px：改为上下堆叠，文案在上、猫猫在下；便当格转为两列再转单列

各宽度均无横向溢出。

### 已知待定项

- 猫猫目前是静态立绘，倾斜与光晕让它有体积感但不会动；要眨眼需要从表情设定图切帧
- 一言接口 `https://v1.hitokoto.cn` 在部分沙箱环境中会被拦截，此时自动回退到内置语录，线上正常
- 底部“SCROLL”提示在手机端贴近边缘，正式实现时建议按实际首屏高度隐藏或上移

## 与最终实现的关系

这份样稿是纯 HTML/CSS/JS 单文件，用来定视觉和交互。正式站点计划用 Astro 重写，届时：

- 拆成 `Base` / `Hero` / `BentoGrid` 等组件
- 视觉参数提取为 CSS 变量（目前已在 `#bentohome` 上集中定义）
- 图片交给 `astro:assets` 处理
- 视差脚本保留现有的指针 + 滚动双通道逻辑（不依赖 `requestAnimationFrame`，在任何环境都能跑）
